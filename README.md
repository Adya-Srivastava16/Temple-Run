🌿 Jungle Rush — Endless Runner Game

A fun, browser-based endless runner game inspired by the classic Temple Run experience. Dodge obstacles, jump over barriers, slide under gates, switch between lanes, and collect coins while challenging yourself to achieve a higher score!

Built using HTML, CSS, and JavaScript, this project runs directly in your web browser without requiring any game engine or external libraries.

🎮 Game Preview

Jungle Rush brings the endless runner concept to life with a jungle-themed environment, a three-lane road, a running character, collectible coins, and randomly generated obstacles.

✨ Features

- 🛣️ Three-Lane Movement: Move left and right to avoid obstacles.
- 🏃 Running Character: Control a character navigating the jungle road.
- ⬆️ Jump Mechanic: Jump over barriers to keep running.
- ⬇️ Slide Mechanic: Slide under overhead gates.
- 🪙 Coin Collection: Collect coins to increase your score.
- 🪨 Random Obstacles: Encounter barriers, gates, and rocks.
- 📈 Increasing Difficulty: Game speed gradually increases as you progress.
- 🏆 Live Scoreboard: Track your score and collected coins.
- 📱 Mobile-Friendly Controls: Play using on-screen buttons on supported mobile browsers.
- 🔄 Restart Option: Start a new run after game over.
- 🌳 Jungle-Themed Graphics: Enjoy a simple illustrated environment created with HTML Canvas.

🛠️ Technologies Used

- HTML5 — Structures the game interface and canvas.
- CSS3 — Styles the game layout, interface, and controls.
- JavaScript — Implements movement, collision detection, scoring, obstacles, coins, and the animation loop.

🚀 Getting Started

Prerequisites

You only need a modern web browser such as Google Chrome, Microsoft Edge, or Firefox.

No installation of Node.js, external libraries, or game engines is required.

Installation

1. Clone the repository

git clone YOUR_REPOSITORY_URL

Replace "YOUR_REPOSITORY_URL" with your actual GitHub repository URL.

2. Open the project folder

cd TempleRun

3. Launch the game

Open "index.html" in your browser.

Alternatively, open the folder in Visual Studio Code and run the project using the Live Server extension.

⚙️ How It Works

1. The game initializes the canvas and player position.
2. Keyboard or mobile input controls lane movement, jumping, and sliding.
3. Obstacles and coins spawn dynamically in different lanes.
4. The animation loop updates object positions and game speed.
5. Collision detection checks whether the player collects a coin or hits an obstacle.
6. The score increases as the player survives and collects coins.
7. The game ends when the player collides with an obstacle without performing the required action.

🎯 Objective

Survive for as long as possible, avoid obstacles, collect as many coins as you can, and beat your previous high score!
